# CDC Data Analysis Projects 📊

Data analysis and machine learning projects using publicly available **CDC (Centers for Disease Control and Prevention)** datasets, exploring population health trends and predictive modeling on real-world epidemiological data.

## Overview

This repository applies ML and statistical analysis techniques to CDC public health datasets — bridging clinical domain knowledge with data science to surface actionable insights from large population-level datasets.

## Analyses Included

- Exploratory data analysis (EDA) on CDC BRFSS / NHANES datasets
- Disease prevalence modeling and risk stratification
- Visualization of population health trends over time
- Predictive modeling for chronic disease outcomes

## Tech Stack

- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, scikit-learn
- **Data Source:** CDC public datasets (BRFSS, NHANES, Wonder)

## How to Run

```bash
git clone https://github.com/drodutola/cdc
cd cdc
pip install -r requirements.txt
jupyter notebook
```
